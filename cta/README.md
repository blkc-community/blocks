# Call to action

A centred heading, supporting text and one button.

Rendered by `CtaBlock` in `@blkc-code/render-web`. See `block.json` for its attributes and an example.

## Make it your own

```bash
npx @blkc-code/cli@latest new block my-cta --from cta
npx @blkc-code/cli@latest dev
```

Edit `blocks/my-cta/render.web.tsx` and save. To use it on a Kit page, list `my-cta` in the Kit's `blocks`.
