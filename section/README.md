# Section

A wrapper with a background and padding around other content.

## Make it your own

```bash
npx @blkc-code/cli@latest new block my-section --from section
npx @blkc-code/cli@latest dev
```

Edit `blocks/my-section/render.web.tsx` and save. To use it on a Kit page, list `my-section` in the Kit's `blocks`.
