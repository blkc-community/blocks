# Hero

Page-top section with heading, supporting copy, calls to action and an optional image.

## Make it your own

```bash
npx @blkc-code/cli@latest new block my-hero --from hero
npx @blkc-code/cli@latest dev
```

Edit `blocks/my-hero/render.web.tsx` and save. To use it on a Kit page, list `my-hero` in the Kit's `blocks`.
