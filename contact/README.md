# Contact

Email, phone and address as links. Forms belong to a capability Block.

Rendered by `ContactBlock` in `@blkc-code/render-web`. See `block.json` for its attributes and an example.

## Make it your own

```bash
npx @blkc-code/cli@latest new block my-contact --from contact
npx @blkc-code/cli@latest dev
```

Edit `blocks/my-contact/render.web.tsx` and save. To use it on a Kit page, list `my-contact` in the Kit's `blocks`.
