# Values

A heading and a grid of short value statements.

Rendered by `ValuesBlock` in `@blkc-code/render-web`. See `block.json` for its attributes and an example.

## Make it your own

```bash
npx @blkc-code/cli@latest new block my-values --from values
npx @blkc-code/cli@latest dev
```

Edit `blocks/my-values/render.web.tsx` and save. To use it on a Kit page, list `my-values` in the Kit's `blocks`.
