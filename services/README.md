# Services

A heading, an intro and a grid of service cards.

Rendered by `ServicesBlock` in `@blkc-code/render-web`. See `block.json` for its attributes and an example.

## Make it your own

```bash
npx @blkc-code/cli@latest new block my-services --from services
npx @blkc-code/cli@latest dev
```

Edit `blocks/my-services/render.web.tsx` and save. To use it on a Kit page, list `my-services` in the Kit's `blocks`.
